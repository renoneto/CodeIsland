## Decisions locked in

- Support **Codex, Claude Code, and Gemini only**. Codex is the default, but all three have static bundled icons.
- Keep the CPU cuts: no animated mascots/timelines, remote/SSH startup, companion-device work, updater checks, sound event work, or recurring hook repair.
- Never hide the monitor based on `activeSessionCount`: it drops to zero whenever an agent temporarily reports `idle`, causing flicker.
- Window visibility is based on `totalSessionCount` (tracked live sessions). It hides only once no session is tracked; process exit and stale-session cleanup remove tracked sessions.
- Hover expansion must not auto-collapse after a synthetic mouse exit caused by notch geometry changing. `⌘⇧I` closes it manually.

## Constraints

- User explicitly rejected generic terminal glyphs; use the static Codex, Claude, and Gemini icon assets.
- Do not reintroduce provider-specific animated mascots or the large upstream provider catalog.
- Do not use desktop automation for QA. Validate pure visibility/hover behavior with XCTest and build/sign checks; macOS physical notch hit-testing remains the only manual observation.
- Existing question-card regression is fixed in `eb30fee`: unrelated Codex activity must not drain a pending Ask User Question.
